# Changelog — OC2O UTILITEY - INFINITY SHEETS

All notable versions of **OC2O UTILITEY - INFINITY SHEETS** (OC20 Utility Tools · [oc2o.co](https://oc2o.co)) are tracked here and tagged in Git.

## [v1.2.0] — Native Pro Engineering UI & PIP Redesign
- **Serious Native macOS / Linear Matte Chrome**: Stripped out glowing gradients, oversized rounded pills, and decorative particles in favor of flat, hairline-bordered edge-to-edge toolbars (`34px` in PIP / `38px` on desktop), crisp `6px–8px` radii, and calm matte canvas surfaces (*Winter Slate*, *Graphite*, *Deep Navy*, *Chalkboard*, *Warm Paper*, *Studio White*).
- **Dedicated Picture-in-Picture (PIP) Mode**: Full-width edge-to-edge `34px` top and bottom bars for compact windows (`< 680px` wide or `< 460px` tall) with an expandable `+` tools tray, giving 82%+ unobstructed canvas space.
- **Restrained OC20 Intro & Sheet Hub**: Fast 1.2s typographic intro (`OC20 Utility Tools · oc2o.co`) and clean, distraction-free Infinity Sheets navigator (`G`).
- **Service Worker v4 (`no-cache` Navigation)**: Ensures GitHub Pages updates load immediately while preserving 100% offline capability.

## [v1.1.0] — GitHub Pages Hosting & 100% Local Browser Storage
- Enabled public static hosting on GitHub Pages (`gh-pages` + automated GitHub Actions workflow) with relative asset paths (`./`) and 100% local-first browser storage.

## [v1.0.0] — Initial Release
- Infinite canvas, infinite sheets, Excalidraw-native direct text & math editing, Visio smart connectors & shape morphing, multi-language LLM code cards, image studio, and `Tab`-linked harmonic color cycling.
